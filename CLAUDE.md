# CLAUDE.md — інструкції для сесій Claude Code у цьому репозиторії

Тестові дані для `click0/zvolrescue`; правила ті самі, що там
(`CLAUDE.md` основного репозиторію), з такими уточненнями:

- `git config core.hooksPath .githooks` — хук додає трейлери атрибуції.
- Відповідати українською; файли в репозиторії англійською, README
  двомовний.
- **Жодних бінарних артефактів у git.** Члени образу лише як реліз-артефакти
  (по файлу на член, `zstd`, ≤ 2 GiB кожен, разом із `SHA256SUMS`). Git LFS
  не вмикати. У git — лише текст: оракул, маніфести, `IMAGE.md`.
- Оракул ніколи не перегенеровується інструментом, що тестується: лише з
  віртуалки під час збірки образу (`zdb`, `sha256`, `zpool status`).
- Образ незмінний: зміна = нова збірка + новий тег `image-vN`; старі теги
  не переписуються, бо на них посилається CI zvolrescue.
- Очікуваний результат у маніфесті виводиться з надмірності ZFS для цієї
  комбінації пошкоджень, не з поведінки поточної версії інструмента.
- Теги через проксі не пушаться — релізи створює користувач.
